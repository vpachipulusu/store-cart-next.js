# SaaS Boilerplate Application - Complete Specification (Next.js 16)

Create a production-ready SaaS boilerplate application with the following modern tech stack and comprehensive testing coverage:

## Core Technology Stack

### Frontend
- **Next.js 16** (App Router with TypeScript)
- **React 19** with Server/Client Components and Server Actions
- **shadcn/ui** with Tailwind CSS (replacing Material-UI)
- **Radix UI** primitives for accessible components
- **TanStack Query v5** for server state management and caching
- **Zustand v5** for client state management
- **Tailwind CSS v4** for styling
- **Responsive design** with mobile-first approach
- **next/font** for optimized font loading

### Backend
- **Next.js 16 API Routes** and Server Actions
- **Prisma ORM v6** with PostgreSQL database
- **Lucia Auth v4** (modern alternative to Firebase Auth)
- **Server Actions** for mutations and form handling
- **Middleware-based** authentication and rate limiting
- **Parallel Routes** for advanced layouts
- **Intercepting Routes** for modals

### Payment & Subscriptions
- **Stripe integration** with webhook handling using Server Actions
- **Stripe Elements v2** with modern UI components
- **Subscription tiers** (Free, Pro, Enterprise)
- **Customer portal** for subscription management
- **Usage tracking** and billing
- **React Server Actions** for payment processing

### Testing & Quality Assurance
- **Vitest** for unit and integration testing (faster than Jest)
- **React Testing Library v16** for component testing
- **Playwright v1.50+** for E2E testing
- **BDD approach** with Behavior-Driven Development patterns
- **Test coverage** minimum 80% for business logic
- **MSW v2** (Mock Service Worker) for API mocking
- **Testing Library User Event v14** for user interactions

### Deployment
- **Vercel-optimized** configuration with Next.js 16
- **Edge Runtime** support with middleware
- **Partial Prerendering (PPR)** enabled
- **Turbopack** for faster development
- **Environment variable** management
- **CI/CD pipeline** with automated testing
- **Server Actions** for zero-client JavaScript mutations
- **Capacitor v6** for native mobile deployment (iOS App Store & Google Play Store)
- **Progressive Web App (PWA)** ready with next-pwa
- **Mobile-first responsive design** for seamless native experience

  email         String    @unique
  emailVerified Boolean   @default(false)
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt

  settings      UserSettings?
  loginHistory  LoginHistory[]
  notifications Notification[]
  adminUser     AdminUser?
  
  @@index([email])
  @@index([firebaseUid])
  @@map("users")

## Testing Strategy & BDD Implementation

### Test Structure (BDD Pattern with Vitest)

Each business logic module should have comprehensive test coverage following BDD:

```typescript
// Example: src/__tests__/unit/utils/validation.test.ts
import { describe, it, expect } from 'vitest';
import {
  validateEmail,
  validatePassword,
} from '@/lib/utils/validation';

describe('Validation Utils', () => {
  describe('Email Validation', () => {
    describe('Given a valid email address', () => {
      it('should return true for standard email format', () => {
        expect(validateEmail('user@example.com')).toBe(true);
      });

      it('should return true for email with subdomains', () => {
        expect(validateEmail('user@mail.example.com')).toBe(true);
      });

      it('should return true for email with plus addressing', () => {
        expect(validateEmail('user+tag@example.com')).toBe(true);
      });
    });

    describe('Given an invalid email address', () => {
      it('should return false for missing @ symbol', () => {
        expect(validateEmail('userexample.com')).toBe(false);
      });

      it('should return false for missing domain', () => {
        expect(validateEmail('user@')).toBe(false);
      });

      it('should return false for spaces in email', () => {
        expect(validateEmail('user @example.com')).toBe(false);
      });

      it('should return false for empty string', () => {
        expect(validateEmail('')).toBe(false);
      });
    });
  });

  describe('Password Validation', () => {
    describe('Given a valid password', () => {
      it('should accept password with 8 characters', () => {
        const result = validatePassword('pass1234');
        expect(result.valid).toBe(true);
        expect(result.message).toBeUndefined();
      });

      it('should accept password with 20 characters', () => {
        const result = validatePassword('a'.repeat(20));
        expect(result.valid).toBe(true);
      });
    });

    describe('Given an invalid password', () => {
      it('should reject password with less than 8 characters', () => {
        const result = validatePassword('pass12');
        expect(result.valid).toBe(false);
        expect(result.message).toBe('Password must be at least 8 characters long');
      });

      it('should reject empty password', () => {
        const result = validatePassword('');
        expect(result.valid).toBe(false);
      });
    });
  });
});
```

### Server Actions Tests (Next.js 16 with Firebase)

```typescript
// Example: src/__tests__/unit/actions/auth-actions.test.ts
import { describe, it, expect, vi, beforeEach } from 'vitest';
import { verifyAndSyncUser } from '@/app/actions/auth-actions';
import { adminAuth } from '@/lib/firebase/admin';
import { db } from '@/lib/db/client';

vi.mock('@/lib/firebase/admin');
vi.mock('@/lib/db/client');

describe('Auth Actions', () => {
  beforeEach(() => {
    vi.clearAllMocks();
  });

  describe('verifyAndSyncUser', () => {
    describe('Given a valid Firebase ID token', () => {
      it('should create new user and return success', async () => {
        const mockToken = 'valid-token';
        const mockUid = 'firebase-uid-123';
        const mockEmail = 'test@example.com';

        vi.mocked(adminAuth.verifyIdToken).mockResolvedValue({
          uid: mockUid,
          email: mockEmail,
          email_verified: true,
        } as any);

        vi.mocked(db.user.findUnique).mockResolvedValue(null);
        vi.mocked(db.user.create).mockResolvedValue({
          id: 'user-123',
          firebaseUid: mockUid,
          email: mockEmail,
        } as any);

        vi.mocked(adminAuth.createSessionCookie).mockResolvedValue('session-cookie');

        const result = await verifyAndSyncUser(mockToken);

        expect(result.success).toBe(true);
        expect(adminAuth.verifyIdToken).toHaveBeenCalledWith(mockToken);
        expect(db.user.create).toHaveBeenCalled();
      });

      it('should update existing user and return success', async () => {
        const mockToken = 'valid-token';
        const mockUid = 'firebase-uid-123';
        const mockEmail = 'test@example.com';

        vi.mocked(adminAuth.verifyIdToken).mockResolvedValue({
          uid: mockUid,
          email: mockEmail,
          email_verified: true,
        } as any);

        vi.mocked(db.user.findUnique).mockResolvedValue({
          id: 'user-123',
          firebaseUid: mockUid,
          email: mockEmail,
        } as any);

        vi.mocked(db.user.update).mockResolvedValue({} as any);
        vi.mocked(adminAuth.createSessionCookie).mockResolvedValue('session-cookie');

        const result = await verifyAndSyncUser(mockToken);

        expect(result.success).toBe(true);
        expect(db.user.update).toHaveBeenCalled();
      });
    });

    describe('Given an invalid Firebase ID token', () => {
      it('should return error when token verification fails', async () => {
        const mockToken = 'invalid-token';

        vi.mocked(adminAuth.verifyIdToken).mockRejectedValue(
          new Error('Token verification failed')
        );

        const result = await verifyAndSyncUser(mockToken);

        expect(result.success).toBe(false);
        expect(result.error).toBeTruthy();
      });
    });
  });
});
```

### React Component Tests (shadcn/ui)

```typescript
// Example: src/__tests__/components/LoginForm.test.tsx
import { describe, it, expect, vi } from 'vitest';
import { render, screen, fireEvent, waitFor } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import LoginForm from '@/components/auth/login-form';

describe('LoginForm Component', () => {
  describe('Form Rendering', () => {
    it('should render email and password inputs', () => {
      render(<LoginForm />);

      expect(screen.getByLabelText(/email/i)).toBeInTheDocument();
      expect(screen.getByLabelText(/password/i)).toBeInTheDocument();
    });

    it('should render login button', () => {
      render(<LoginForm />);

      expect(screen.getByRole('button', { name: /log in/i })).toBeInTheDocument();
    });
  });

  describe('Form Validation', () => {
    it('should show error for invalid email', async () => {
      const user = userEvent.setup();
      render(<LoginForm />);

      const emailInput = screen.getByLabelText(/email/i);
      await user.type(emailInput, 'invalid-email');
      await user.tab();

      await waitFor(() => {
        expect(screen.getByText(/invalid email format/i)).toBeInTheDocument();
      });
    });

    it('should show error for short password', async () => {
      const user = userEvent.setup();
      render(<LoginForm />);

      const passwordInput = screen.getByLabelText(/password/i);
      await user.type(passwordInput, '12345');
      await user.tab();

      await waitFor(() => {
        expect(screen.getByText(/password must be at least 8 characters/i)).toBeInTheDocument();
      });
    });
  });

  describe('Form Submission', () => {
    it('should submit with correct credentials', async () => {
      const user = userEvent.setup();
      const mockLogin = vi.fn();
      
      render(<LoginForm onSubmit={mockLogin} />);

      await user.type(screen.getByLabelText(/email/i), 'test@example.com');
      await user.type(screen.getByLabelText(/password/i), 'password123');
      await user.click(screen.getByRole('button', { name: /log in/i }));

      await waitFor(() => {
        expect(mockLogin).toHaveBeenCalledWith({
          email: 'test@example.com',
          password: 'password123',
        });
      });
    });

    it('should disable submit button during submission', async () => {
      const user = userEvent.setup();
      render(<LoginForm />);

      const submitButton = screen.getByRole('button', { name: /log in/i });
      await user.click(submitButton);

      expect(submitButton).toBeDisabled();
    });
  });
});
```

### Mobile Platform Detection Hook
```typescript
// hooks/use-mobile-platform.ts
'use client';

import { useEffect, useState } from 'react';
import { Capacitor } from '@capacitor/core';

export function useMobilePlatform() {
  const [platform, setPlatform] = useState<{
    isNative: boolean;
    isIOS: boolean;
    isAndroid: boolean;
    isWeb: boolean;
  }>({
    isNative: false,
    isIOS: false,
    isAndroid: false,
    isWeb: true,
  });

  useEffect(() => {
    const isNative = Capacitor.isNativePlatform();
    const platformName = Capacitor.getPlatform();

    setPlatform({
      isNative,
      isIOS: platformName === 'ios',
      isAndroid: platformName === 'android',
      isWeb: platformName === 'web',
    });
  }, []);

  return platform;
}
```

```typescript
// lib/capacitor/index.ts
'use client';

import { Capacitor } from '@capacitor/core';
import { App } from '@capacitor/app';
import { StatusBar, Style } from '@capacitor/status-bar';
import { SplashScreen } from '@capacitor/splash-screen';
import { Keyboard } from '@capacitor/keyboard';
import { Haptics, ImpactStyle } from '@capacitor/haptics';
import { Preferences } from '@capacitor/preferences';

export const isNativePlatform = () => Capacitor.isNativePlatform();

// App state management
export const setupAppListeners = () => {
  if (!isNativePlatform()) return;

  App.addListener('appStateChange', ({ isActive }) => {
    console.log('App state changed. Is active:', isActive);
  });

  App.addListener('backButton', ({ canGoBack }) => {
    if (!canGoBack) {
      App.exitApp();
    } else {
      window.history.back();
    }
  });
};

// Status bar configuration
export const configureStatusBar = async (isDark: boolean) => {
  if (!isNativePlatform()) return;

  try {
    await StatusBar.setStyle({
      style: isDark ? Style.Dark : Style.Light,
    });
  } catch (error) {
    console.error('Error configuring status bar:', error);
  }
};

// Splash screen
export const hideSplashScreen = async () => {
  if (!isNativePlatform()) return;

  try {
    await SplashScreen.hide();
  } catch (error) {
    console.error('Error hiding splash screen:', error);
  }
};

// Keyboard management
export const setupKeyboard = () => {
  if (!isNativePlatform()) return;

  Keyboard.addListener('keyboardWillShow', info => {
    console.log('Keyboard will show with height:', info.keyboardHeight);
  });

  Keyboard.addListener('keyboardWillHide', () => {
    console.log('Keyboard will hide');
  });
};

// Haptic feedback
export const triggerHaptic = async (style: ImpactStyle = ImpactStyle.Medium) => {
  if (!isNativePlatform()) return;

  try {
    await Haptics.impact({ style });
  } catch (error) {
    console.error('Error triggering haptic:', error);
  }
};

// Preferences (local storage for mobile)
export const setPreference = async (key: string, value: string) => {
  if (!isNativePlatform()) {
    localStorage.setItem(key, value);
    return;
  }

  try {
    await Preferences.set({ key, value });
  } catch (error) {
    console.error('Error setting preference:', error);
  }
};

export const getPreference = async (key: string): Promise<string | null> => {
  if (!isNativePlatform()) {
    return localStorage.getItem(key);
  }

  try {
    const { value } = await Preferences.get({ key });
    return value;
  } catch (error) {
    console.error('Error getting preference:', error);
    return null;
  }
};

export const removePreference = async (key: string) => {
  if (!isNativePlatform()) {
    localStorage.removeItem(key);
    return;
  }

  try {
    await Preferences.remove({ key });
  } catch (error) {
    console.error('Error removing preference:', error);
  }
};
```

### Admin Middleware & Security

**adminAuth Middleware:**
```typescript
// lib/middleware/adminAuth.ts
export async function requireAdmin(request: NextRequest) {
  const user = await authenticateRequest(request);
  
  const adminUser = await prisma.adminUser.findUnique({
    where: { userId: user.userId },
  });
  
  if (!adminUser) {
    throw new Error('Unauthorized: Admin access required');
  }
  
  return { ...user, adminRole: adminUser.role, permissions: adminUser.permissions };
}

export function requirePermission(permission: string) {
  return async (request: NextRequest) => {
    const admin = await requireAdmin(request);
    
    if (!admin.permissions.includes(permission) && admin.adminRole !== 'super_admin') {
      throw new Error(`Unauthorized: Missing permission '${permission}'`);
    }
    
    return admin;
  };
}
```

```typescript
import { create } from 'zustand';
import { devtools } from 'zustand/middleware';

interface AdminState {
  selectedUsers: string[];
  filters: {
    tier?: string;
    status?: string;
    search?: string;
  };
  toggleUserSelection: (userId: string) => void;
  clearSelection: () => void;
  setFilters: (filters: Partial<AdminState['filters']>) => void;
  clearFilters: () => void;
}

export const useAdminStore = create<AdminState>()(
  devtools(
    (set) => ({
      selectedUsers: [],
      filters: {},
      toggleUserSelection: (userId) =>

          selectedUsers: state.selectedUsers.includes(userId)
            ? state.selectedUsers.filter((id) => id !== userId)
            : [...state.selectedUsers, userId],
        })),
      clearSelection: () => set({ selectedUsers: [] }),
      setFilters: (filters) =>
        set((state) => ({ filters: { ...state.filters, ...filters } })),
      clearFilters: () => set({ filters: {} }),
    }),
    { name: 'AdminStore' }
  )
);
```

### Auth Server Actions (Firebase)
```typescript
// app/actions/auth-actions.ts
'use server';

import { adminAuth } from '@/lib/firebase/admin';
import { db } from '@/lib/db/client';
import { cookies } from 'next/headers';
import { redirect } from 'next/navigation';
import { z } from 'zod';

const loginSchema = z.object({
  email: z.string().email('Invalid email address'),
  password: z.string().min(8, 'Password must be at least 8 characters'),
});

// Note: Client-side Firebase auth happens in the component
// This server action verifies and creates/updates user in database
export async function verifyAndSyncUser(
  idToken: string
): Promise<{ success: boolean; error?: string }> {
  try {
    // Verify Firebase ID token
    const decodedToken = await adminAuth.verifyIdToken(idToken);
    const { uid, email, email_verified } = decodedToken;

    // Find or create user in database
    let user = await db.user.findUnique({
      where: { firebaseUid: uid },
    });

    if (!user) {
      user = await db.user.create({
        data: {
          firebaseUid: uid,
          email: email!,
          emailVerified: email_verified || false,
        },
      });
    } else {
      // Update last login
      await db.user.update({
        where: { id: user.id },
        data: { lastLoginAt: new Date() },
      });
    }

    // Set session cookie
    const expiresIn = 60 * 60 * 24 * 5 * 1000; // 5 days
    const sessionCookie = await adminAuth.createSessionCookie(idToken, {
      expiresIn,
    });

    (await cookies()).set('session', sessionCookie, {
      maxAge: expiresIn,
      httpOnly: true,
      secure: process.env.NODE_ENV === 'production',
      sameSite: 'lax',
      path: '/',
    });

    return { success: true };
  } catch (error: any) {
    console.error('Auth error:', error);
    return { success: false, error: error.message || 'Authentication failed' };
  }
}

export async function logoutAction() {
  const sessionCookie = (await cookies()).get('session');
  
  if (sessionCookie) {
    try {
      const decodedClaims = await adminAuth.verifySessionCookie(
        sessionCookie.value
      );
      await adminAuth.revokeRefreshTokens(decodedClaims.uid);
    } catch (error) {
      // Session already invalid
    }
  }
  
  (await cookies()).delete('session');
  redirect('/login');
}
```

```typescript
// lib/middleware/admin-auth.ts
import { adminAuth } from '@/lib/firebase/admin';
import { cookies } from 'next/headers';
import { db } from '@/lib/db/client';

export async function requireAdmin() {
  const sessionCookie = (await cookies()).get('session');
  
  if (!sessionCookie) {
    throw new Error('Unauthorized: No session found');
  }

  try {
    // Verify Firebase session cookie
    const decodedClaims = await adminAuth.verifySessionCookie(
      sessionCookie.value,
      true
    );

    // Get user from database
    const user = await db.user.findUnique({
      where: { firebaseUid: decodedClaims.uid },
      include: { adminUser: true },
    });

    if (!user || !user.adminUser) {
      throw new Error('Unauthorized: Admin access required');
    }

    return {
      userId: user.id,
      firebaseUid: decodedClaims.uid,
      adminRole: user.adminUser.role,
      permissions: user.adminUser.permissions as string[],
    };
  } catch (error) {
    throw new Error('Unauthorized: Invalid session');
  }
}

export function hasPermission(
  permissions: string[],
  role: string,
  requiredPermission: string
): boolean {
  if (role === 'super_admin') return true;
  return permissions.includes(requiredPermission);
}
```

### Next.js Middleware (Route Protection with Firebase)
```typescript
// middleware.ts
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';
import { adminAuth } from '@/lib/firebase/admin';
import { db } from '@/lib/db/client';

export async function middleware(request: NextRequest) {
  const sessionCookie = request.cookies.get('session');
  
  // Protected routes
  const protectedPaths = ['/dashboard', '/profile', '/settings'];
  const adminPaths = ['/admin'];
  const authPaths = ['/login', '/signup'];
  
  const path = request.nextUrl.pathname;
  
  // Check if path requires authentication
  const isProtectedPath = protectedPaths.some((p) => path.startsWith(p));
  const isAdminPath = adminPaths.some((p) => path.startsWith(p));
  const isAuthPath = authPaths.some((p) => path.startsWith(p));
  
  // No session cookie
  if (!sessionCookie) {
    if (isProtectedPath || isAdminPath) {
      return NextResponse.redirect(new URL('/login', request.url));
    }
    return NextResponse.next();
  }

  // Validate session
  try {
    const decodedClaims = await adminAuth.verifySessionCookie(
      sessionCookie.value,
      true
    );

    // Authenticated user accessing auth pages
    if (isAuthPath) {
      return NextResponse.redirect(new URL('/dashboard', request.url));
    }

    // Check admin access
    if (isAdminPath) {
      const user = await db.user.findUnique({
        where: { firebaseUid: decodedClaims.uid },
        include: { adminUser: true },
      });

      if (!user?.adminUser) {
        return NextResponse.redirect(new URL('/dashboard', request.url));
      }
    }

    return NextResponse.next();
  } catch (error) {
    // Invalid session
    if (isProtectedPath || isAdminPath) {
      return NextResponse.redirect(new URL('/login', request.url));
    }
    return NextResponse.next();
  }
}

export const config = {
  matcher: ['/((?!api|_next/static|_next/image|favicon.ico).*)'],
};
```

```typescript
import { db } from '@/lib/db/client';
import { logAdminAction } from './audit-log.service';
import { unstable_cache } from 'next/cache';

export const listUsers = unstable_cache(
  async (params: {
    page: number;
    limit: number;
    search?: string;
    tier?: string;
    status?: string;
  }) => {
    const { page, limit, search, tier, status } = params;
    const skip = (page - 1) * limit;

    const where: any = {};
    
    if (search) {
      where.OR = [
        { email: { contains: search, mode: 'insensitive' } },
        { displayName: { contains: search, mode: 'insensitive' } },
      ];
    }
    
    if (tier) {
      where.subscriptionTier = tier;
    }
    
    if (status) {
      where.subscriptionStatus = status;
    }

    const [users, total] = await Promise.all([
      db.user.findMany({
        where,
        skip,
        take: limit,
        orderBy: { createdAt: 'desc' },
        include: {
          settings: true,
          _count: {
            select: { loginHistory: true },
          },
        },
      }),
      db.user.count({ where }),
    ]);

    return {
      users,
      total,
      pages: Math.ceil(total / limit),
      currentPage: page,
    };
  },
  ['admin-users'],
  { revalidate: 60, tags: ['admin-users'] }
);
```

```typescript
// lib/capacitor/push-notifications.ts
import { PushNotifications } from '@capacitor/push-notifications';

export const requestNotificationPermission = async () => {
  const permStatus = await PushNotifications.checkPermissions();
  
  if (permStatus.receive !== 'granted') {
    const result = await PushNotifications.requestPermissions();
    return result.receive === 'granted';
  }
  
  return true;
};

export const registerForPushNotifications = async () => {
  const hasPermission = await requestNotificationPermission();
  
  if (!hasPermission) {
    throw new Error('Push notification permission denied');
  }

  await PushNotifications.register();

  PushNotifications.addListener('registration', async token => {
    console.log('Push registration success, token:', token.value);
    // Send token to your backend
    await fetch('/api/notifications/register', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ token: token.value }),
    });
  });

  PushNotifications.addListener('registrationError', error => {
    console.error('Push registration error:', error);
  });

  PushNotifications.addListener('pushNotificationReceived', notification => {
    console.log('Push notification received:', notification);
  });

  PushNotifications.addListener('pushNotificationActionPerformed', notification => {
    console.log('Push notification action performed:', notification);
  });
};
```

### Secure Storage for Tokens
```typescript
// lib/capacitor/secure-storage.ts
import { Capacitor } from '@capacitor/core';
import { SecureStoragePlugin } from 'capacitor-secure-storage-plugin';

const isNative = Capacitor.isNativePlatform();

export const secureStorage = {
  async set(key: string, value: string): Promise<void> {
    if (isNative) {
      await SecureStoragePlugin.set({ key, value });
    } else {
      localStorage.setItem(key, value);
    }
  },

  async get(key: string): Promise<string | null> {
    if (isNative) {
      try {
        const { value } = await SecureStoragePlugin.get({ key });
        return value;
      } catch {
        return null;
      }
    } else {
      return localStorage.getItem(key);
    }
  },

  async remove(key: string): Promise<void> {
    if (isNative) {
      await SecureStoragePlugin.remove({ key });
    } else {
      localStorage.removeItem(key);
    }
  },

  async clear(): Promise<void> {
    if (isNative) {
      await SecureStoragePlugin.clear();
    } else {
      localStorage.clear();
    }
  },
};
```

## Mobile Development Best Practices

### 1. Network Resilience
```typescript
// lib/api/mobile-fetch.ts
import { Capacitor } from '@capacitor/core';
import { Network } from '@capacitor/network';

let isOnline = true;

export const setupNetworkListener = () => {
  if (!Capacitor.isNativePlatform()) return;

  Network.addListener('networkStatusChange', status => {
    isOnline = status.connected;
    console.log('Network status changed:', status);
  });
};

export const mobileFetch = async (url: string, options?: RequestInit) => {
  if (!isOnline) {
    throw new Error('No internet connection');
  }

  try {
    const response = await fetch(url, {
      ...options,
      signal: AbortSignal.timeout(30000), // 30s timeout
    });
    return response;
  } catch (error) {
    if (error instanceof Error && error.name === 'AbortError') {
      throw new Error('Request timeout');
    }
    throw error;
  }
};
```

### 2. Memory Management
```typescript
// hooks/use-image-optimization.ts
'use client';

import { useState, useEffect } from 'react';
import { useMobilePlatform } from './use-mobile-platform';

export function useImageOptimization(src: string) {
  const { isNative } = useMobilePlatform();
  const [optimizedSrc, setOptimizedSrc] = useState(src);

  useEffect(() => {
    if (isNative && src.startsWith('http')) {
      // Resize images for mobile devices
      const url = new URL(src);
      url.searchParams.set('w', '800'); // Max width
      url.searchParams.set('q', '75'); // Quality
      setOptimizedSrc(url.toString());
    }
  }, [src, isNative]);

  return optimizedSrc;
}
```

```typescript
// lib/capacitor/battery-optimization.ts
import { BackgroundTask } from '@capawesome/capacitor-background-task';

export const runBackgroundTask = async (task: () => Promise<void>) => {
  const taskId = await BackgroundTask.beforeExit(async () => {
    try {
      await task();
    } finally {
      BackgroundTask.finish({ taskId });
    }
  });
};
```

```typescript
// lib/capacitor/app-updates.ts
import { App } from '@capacitor/app';
import { Capacitor } from '@capacitor/core';

export const checkForUpdates = async () => {
  if (!Capacitor.isNativePlatform()) return;

  const info = await App.getInfo();
  
  // Check your backend for latest version
  const response = await fetch('/api/app-version');
  const { latestVersion } = await response.json();
```
